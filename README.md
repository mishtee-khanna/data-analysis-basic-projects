## 🌸 About This Repository

Welcome to my **Python Basic Projects** repository — a growing collection of small, practical applications built while strengthening my Python fundamentals and problem-solving skills.

Each project focuses on a different concept, from **GUI development and games to automation, file handling, and simple utilities**.

> 💡 **Learn → Build → Experiment → Improve → Repeat**

This repository is **actively maintained** as I continue learning and adding new projects.

---

## 🚀 Projects

| 🧩 Project | 📝 Description | 🛠️ Focus |
|---|---|---|
| 🧮 **Calculator** | GUI-based calculator for performing common arithmetic operations. | Tkinter, GUI |
| 🐍 **Snake Game** | Classic Snake game with keyboard controls and scoring. | Python, Game Logic |
| 🎮 **Snake Water Gun** | Command-line game inspired by Rock Paper Scissors. | Conditions, Random |
| ⌨️ **Typing Test** | Tests typing speed and accuracy using timed input. | Time, Strings |
| 🧠 **Quiz** | Interactive quiz program with questions and score tracking. | Functions, Logic |
| 🔐 **Password Manager** | Simple utility for storing and managing passwords. | File Handling |
| 📄 **PDF Merger** | Combines multiple PDF files into a single document. | Automation, PyPDF |
| 💧 **Drink Water Reminder** | Desktop reminder utility to encourage regular water breaks. | Time, Notifications |
